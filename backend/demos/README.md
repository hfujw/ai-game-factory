# Demo 页面

这个目录存放预生成的示例 HTML 页面，访客点击首页的演示按钮即可零成本浏览成品。

## 如何生成

1. 本地启动后端和前端
2. 在搜索框输入对应主题，等生成完毕
3. 从浏览器开发者工具 Network 标签找到 `page_ready` 消息，复制 `page_html` 字段
4. 保存为 `{主题名}.html` 放在这个目录下
